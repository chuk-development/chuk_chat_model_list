# Chuk Chat model list

This repository contains the current list of models available in Chuk Chat.

Based on https://chuk.chat/en/, Chuk Chat is a private AI chat app focused on encrypted chats, no tracking, no data mining, and open-weight models.

Main Chuk Chat repository: https://github.com/chuk-development/chuk_chat
